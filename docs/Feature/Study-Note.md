# Study Note

Use **Study Note** to record reminders, class notes, instructor announcements, and more.

::: info Local storage
All Study Note data stays in your local browser profile. There is no cloud saving, and notes are not encrypted by BB Better Layout.
:::





![bb_Study_note](https://img.dukehsu.com/blog/bb_Study_note.webp) 

## Key Features

- Open Study Note with a keyboard shortcut for quick capture.
- Export notes as JSON or CSV.
- Import a JSON or CSV backup.
- Write and preview Markdown.

::: warning Importing appends data
Imported data is added to your existing notes. Importing the same backup more than once may create duplicates.
:::
