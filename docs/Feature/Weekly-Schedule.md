# Weekly Schedule

The basic Weekly Schedule is built into BB Better Layout. You can import courses from the current semester and display them in a weekly timetable inside Blackboard.

::: tip More export options
For advanced features such as exporting a phone wallpaper or PDF, use [Weekly Schedule Maker](https://weekly.52hz.im).
:::



![BB-schedule](https://img.dukehsu.com/blog/bb-schedule.webp)

## Key Features

- Import courses directly from Blackboard Courses into the timetable.
- Show the section, course name, instructor, and meeting time.
- Add schedule entries manually.
