# Appearance

In **Appearance**, you can choose your preferred interface colors and set a cover image for Course Content pages.

![Appearance Setup](https://img.dukehsu.com/blog/apperance.webp) 

## Interface Color Scheme



- Default Light
- Nord Snow
- Paper Reading 
- Sage Reading
- Sky Reading
- Lavender Reading
- Graphite Reading
- Aqua Reading
- Rose Pink

## Course Content Cover Image

- You can set one local image for all course pages.
- For the best fit, use an image that is 2366 × 225 pixels.
