# Custom External Links

Add your own link destinations to Blackboard's main side panel.

![BB_external_link](https://img.dukehsu.com/blog/bb_external_link.webp) 

- You can turn this feature on or off at any time.
- When you add a link, enter its name and URL, then choose an icon.
- Select **Save External Links** after you finish.
- You can add up to six links to keep the side panel tidy.
