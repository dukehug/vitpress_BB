Visit Firefox Browser Add-ons and select **Add to Firefox**.

## Pin It to Your Browser Toolbar

### Chrome

1. Select the **Extensions** puzzle-piece icon in the upper-right corner of Chrome.
2. Find **BB Better Layout** in the list.
3. Select the **Pin** icon beside it. The extension icon will stay visible next to the address bar.

### Firefox

1. Select the **Extensions** puzzle-piece icon in the upper-right corner of Firefox.
2. Find **BB Better Layout**, then select the **Settings** gear beside it.
3. Select **Pin to Toolbar**.

You can now open BB Better Layout directly from your browser toolbar.
